# Aqeedah

A bilingual (Uzbek + English) Islamic question-and-answer platform.

## Current stage: design proposal

`design/index.html` is the first proposal: research on existing Islamic Q&A sites,
the proposed feature set, user roles, site structure and screen mockups.
Nothing of the app itself is built yet.

## Deploy

This is a static site with no build step. On Vercel, import this repository
with the framework preset "Other"; the root `index.html` opens the proposal.
